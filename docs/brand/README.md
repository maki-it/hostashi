# Hostashi logo

The logo is a coral tile with an "H", next to the name set in Sora Bold. The same mark is the panel's favicon and the badge in its sidebar.

| File | Use |
| --- | --- |
| [`hostashi-logo-light.svg`](hostashi-logo-light.svg) | Logo on light backgrounds |
| [`hostashi-logo-dark.svg`](hostashi-logo-dark.svg) | Logo on dark backgrounds |
| [`hostashi-mark.svg`](hostashi-mark.svg) | The mark alone, for avatars and small spaces |
| [`social-preview.png`](social-preview.png) | Link preview, 1280 × 640 (GitHub: Settings → Social preview) |

The panel's icons live in [`web/public/`](../../web/public/): `favicon.svg`, `favicon.ico` (16, 32 and 48 px, the 16 px size drawn on the pixel grid) and `apple-touch-icon.png` (180 px, square; the device rounds the corners).

## Colours

| Name | Value |
| --- | --- |
| Coral (tile) | `#ff6f61` |
| Ink (the "H", text on light) | `#0d1f1a` |
| Paper (text on dark) | `#fdfcfa` |

## Rules

- Keep the tile, the "H" and the name as they are; do not stretch, recolour or outline them.
- Leave free space around the logo of at least half the tile's height.
- The name in the SVG files is converted to outlines, so it needs no font. Sora is licensed under the SIL Open Font License 1.1.
